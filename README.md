# VeterinariaAPP

Sistema de ventas, inventario y reportes para una veterinaria con 3 sucursales.

- Vende **productos y servicios**, con método de pago y cierre de caja por sucursal.
- Inventario por lote con **alertas en rojo** por vencimiento próximo y por stock bajo.
- Cada sucursal **trabaja sin internet** y sincroniza con un **servidor central** donde la oficina ve todo.
- **No imprime ni emite factura fiscal**: es de uso interno, para control y reportes.

**Estado:** diseño. Todavía no hay código.
